# Ready at Home — repository instructions

## Read first

Before significant work, read `AGENTS.md`, `PROJECT.md`, `README.md` and the relevant page/legal files.

## Product boundary

This is the sales site for the UK and US Ready at Home guide + workbook bundles. The current milestone is launch verification, not expansion into a broader preparedness platform.

## Safety and content integrity

- Do not invent emergency, medical, legal or government guidance.
- Keep UK and US editions distinct where advice differs.
- Preserve clear product/pricing distinctions by region.
- Do not claim purchase/delivery success unless tested.
- Do not expose private Payhip/admin credentials.

## Deployment

The site is static and currently published through GitHub Pages. Changes to `main` can affect the public preview.

Treat DNS/custom-domain changes as operational actions requiring explicit user intent. Do not alter domain records from code.

## Documentation is part of done

Update `PROJECT.md` when launch state, domain state, pricing, checkout, legal readiness or the next milestone changes.

Update `README.md` when stable setup or deployment instructions change.

## Handoff

Read `PROJECT.md` first; finish by updating it with the current launch state and next action.
