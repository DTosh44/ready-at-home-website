# Ready at Home landing page

Deploy-ready static landing page for `getreadyathome.com`.

## Before publishing

1. Replace the UK checkout link in `index.html` on the element with `data-checkout="uk"`.
2. Connect the form with `id="lead-form"` to the selected email provider and remove the temporary JavaScript interception.
3. Add Privacy, Terms, Refund and Disclaimer pages once the selling/email platforms are selected.
4. Add the finished US product and route when it has been quality checked.
5. Test the live checkout, delivery email and lead-magnet automation from start to finish.
6. Point `getreadyathome.com` to the chosen host; redirect `getreadyathome.co.uk` to the UK route.

## Preview locally

Run a local web server from this folder, then open the address it supplies in a browser.

The page has no build step and can be hosted on any static host.
